# Modelling C. elegans endomesoderm specification with GRS.jl

Using [GeneRegulatorySystems.jl](https://github.com/drostlab/GeneRegulatorySystems.jl).

Data sources:

- EMS regulatory network and knockout data:
_Ewe CK, Sommermann EM, Kenchel J, Flowers SE, Maduro MF, Joshi PM, Rothman JH. Feedforward regulatory logic controls the specification-to-differentiation transition and terminal cell fate during Caenorhabditis elegans endoderm development. Development 149(12), dev200337 (2022). doi:10.1242/dev.200337_
- single-cell omics data:
_van der Burght SN, Carelli FN, Appert A, Dong Y, Hill M, Buttress T, Butler R, Ahringer J. A lineage-resolved multimodal single-cell atlas reveals the genomic dynamics of early C. elegans development. bioRxiv (2024). doi:10.1101/2024.12.02.626321_
- cell cycle durations:
_Guan G, Li Z, Ma Y, Ye P, Cao J, Wong MK, Ho VWS, Chan LY, Yan H, Tang C, Zhao Z. Cell lineage-resolved embryonic morphological map reveals signaling associated with cell fate and size asymmetry. Nature Communications 16, 3700 (2025). doi:10.1038/s41467-025-58878-0_
